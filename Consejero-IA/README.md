# Unitutor IA — Consejero de IA para estudiantes universitarios

## Descripción
Unitutor IA es un proyecto académico diseñado para brindar apoyo a estudiantes universitarios mediante herramientas orientadas al bienestar emocional y la organización académica.

## Funcionalidades
- Consejos emocionales.
- Sección de recordatorios.
- Orientación para manejar el estrés.
- Apoyo en la organización de tareas.

## Tecnologías
- JavaScript
- Code.org App Lab

Explorar cómo una aplicación interactiva puede apoyar a los estudiantes en su organización académica y bienestar emocional.
