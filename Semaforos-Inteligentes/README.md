# 🚦 Sistema de Semáforos Inteligentes con Arduino

## 📌 Descripción

Este proyecto académico consiste en desarrollar un sistema de semáforos inteligentes utilizando Arduino, con el propósito de explorar cómo la tecnología puede contribuir a mejorar la movilidad y la organización del tráfico vehicular.

La propuesta se enfoca en analizar el flujo de vehículos y aplicar lógica de programación para controlar el funcionamiento de los semáforos, buscando una circulación más eficiente.

## 🎯 Objetivos

- Implementar lógica de control de semáforos mediante Arduino.
- Explorar cómo el flujo vehicular puede influir en la gestión del tráfico.
- Aplicar conceptos de programación y electrónica a un problema real.
- Comprender cómo los sistemas automatizados pueden contribuir a la movilidad urbana.

## 🛠️ Tecnologías y herramientas

- **Arduino:** plataforma utilizada para implementar el sistema de control.
- **Programación para Arduino:** desarrollo de instrucciones y condiciones para gestionar el funcionamiento de los semáforos.
- **Componentes electrónicos:** elementos necesarios para representar el funcionamiento del sistema, según el montaje realizado.

## ⚙️ Funcionamiento general

El sistema utiliza Arduino para ejecutar la lógica de funcionamiento de los semáforos.

La idea del proyecto es relacionar el comportamiento del sistema con el flujo vehicular, explorando cómo se puede mejorar la distribución del tráfico mediante decisiones automatizadas.

## 🧠 Conceptos aplicados

- Lógica computacional.
- Programación estructurada.
- Fundamentos de electrónica.
- Sistemas de control.
- Automatización de procesos.
- Resolución de problemas mediante tecnología.

## 📚 Aprendizajes

Con este proyecto se explora la integración entre software y hardware, el uso de Arduino para controlar componentes electrónicos y la aplicación de la programación a situaciones relacionadas con la movilidad urbana.
